# Documentation Archive

This directory contains historical notes that are no longer canonical for the
current `final_v0_1_5` artifact.

Use the current documentation entry point instead:

- `docs/index.md`
- `docs/design/final_benchmark_contract.md`
- `docs/design/split_contract.md`
- `docs/design/llm_run_config_contract.md`
- `docs/results/final_v0_1_5_dev_gemini_flash_lite.md`

Archived files are kept for provenance and design history. They may mention
older seed sets, pilot-generation experiments, obsolete result paths, or
intermediate evaluator behavior. Do not treat archived notes as release
contracts unless a current document explicitly references them.

## Contents

- `design/`: historical design, pilot, discovery, and generation contracts.
- `dwsim/`: historical simulator-integration research notes.
- `results/`: historical pilot, feasibility, and model-run result notes.
